# 🐔 Flappy Chicken

> **Cluck your way to victory in this premium, polished web game!**

Welcome to **Flappy Chicken**, a modern, high-fidelity reimagining of the classic arcade challenge. Built with pure vanilla JavaScript and love, this game brings smooth performance, procedural graphics, and a whole lot of clucking fun to your browser.

▶️ [Play it online](https://aishwaryasingh51.github.io/Flappy_Chicken/)

## ✨ Features

*   **🎨 Procedural Art**: No external image assets! The chicken, pipes, and city skyline are all drawn in real-time using the HTML5 Canvas API.
*   **🚀 Smooth Performance**: Implements a **Delta Time** game loop, ensuring buttery smooth gameplay on 60Hz, 120Hz, and 144Hz screens.
*   **📱 Mobile Ready**: Fully responsive! Tap to flap on your phone, or smash that Spacebar on your desktop.
*   **🏆 Medal System**: Earn shiny rewards for your skills!
    *   🥉 **Bronze**: 5 Points
    *   🥈 **Silver**: 10 Points
    *   🥇 **Gold**: 20 Points
    *   💎 **Platinum**: 50 Points
*   **🎆 High Score Celebration**: Beat your best score to trigger a dazzling fireworks display and a hopping "NEW HIGH SCORE" animation!
*   **💾 Local Save**: Your high score and achievements are saved right in your browser.

## 🎮 How to Play

1.  **Start**: Press `Space` or `Tap` the screen.
2.  **Flap**: Keep tapping/pressing to keep your chicken in the air.
3.  **Dodge**: Avoid the green pipes! Hitting them (or the ground) means game over.
4.  **Score**: Pass pipes to earn points and unlock medals.

## 🛠️ Tech Stack

*   **HTML5**: Semantic structure.
*   **CSS3**: Glassmorphism UI, animations, and responsive layout.
*   **JavaScript (ES6+)**: Game logic, physics engine, and particle systems.

## 🚀 Getting Started

Simply open `index.html` in your favorite web browser to start playing! No build steps or servers required.

```bash
# Clone the repo
git clone https://github.com/yourusername/flappy-chicken.git

# Open the game
open index.html
```
